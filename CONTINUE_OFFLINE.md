# Continue Offline

If you only do one thing next, implement a headless autonomous simulation before building the GTK interface.

A useful checkpoint is:

- Generate 5 factions and ~100 provinces.
- Place several armies.
- Let all factions run under AI for 10 simulated years.
- Print yearly territory, population, casualties, and major events.
- Verify that wars start, fronts move, wars end, and no obvious numerical system explodes.

Only after that loop is interesting should you invest heavily in graphics or tray polish.
