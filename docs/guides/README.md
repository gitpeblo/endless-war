# Guides

How the game works, in plain language. Nothing here assumes you have read the
code.

- **[The world](the-world.md)** — provinces, terrain, factions, supply.
- **[A day in the war](a-day-in-the-war.md)** — what actually happens as time passes.
- **[How wars work](how-wars-work.md)** — why they start, how they are fought, how they end.
- **[Watching a run](watching-a-run.md)** — running it and reading the output.

Everything else under `docs/` is for building the game rather than playing it:
`architecture.md` (how the code is layered), `decisions.md` (why things are the
way they are), `game-logic.md` (the exact formulas and the config keys that tune
them), `development-rules.md`, `data-model.md`, `simulation-notes.md`.
