# A day in the war

Time moves in **ticks of six hours** — four to a day. Every tick, the same
sequence happens everywhere on the map.

**Money comes in.** Each faction earns from the industry of the provinces it
controls, and pays upkeep on the armies it fields.

**Recruits arrive.** A faction can field up to a fraction of the population it
controls. Each tick tops the pool up toward that ceiling, and a war-weary nation
refills more slowly than a fresh one.

**Supply is recalculated.** From every capital and industrial centre, outward
through friendly territory. Provinces cut off this tick start starving this tick.

**Every army decides what to do.** Each one looks only at the provinces next to
it — there is no general staff and no master plan:

- If it is broken, it withdraws toward friendly ground with good supply, unless
  it is already somewhere safe, in which case it stands still and recovers.
- Otherwise, if an enemy province is adjacent, it attacks the weakest one —
  but only if it thinks it outnumbers the defenders. If not, it digs in.
- Otherwise it moves to reinforce a friendly province that borders the enemy.

Front lines are not drawn anywhere in the game. They are just what this looks
like when a hundred armies do it at once.

**Armies move.** One province per tick at most. Moving into an enemy-held
province *is* the attack — there is no separate order for it.

**Battles resolve.** Wherever two hostile armies now stand in the same province.

**Ground changes hands.** An enemy province with nobody left defending it
changes controller. An attacker that has broken is pushed back out.

**The mood shifts.** Casualties this tick raise war exhaustion; peace lets it
fade.

**Diplomacy.** Someone may declare war; someone may make peace.

**History is written.** Anything significant — a war declared, a province taken,
a large battle — goes into the event log.
